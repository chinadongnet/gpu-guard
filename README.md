# GPU Guard — GPU 温度守护托盘应用

把 `gpu-temp-guard.ps1` 的锁频降温逻辑做成 Windows 托盘应用（.NET 10 WinForms）。

## 功能
- 托盘图标（右下角）实时显示 GPU 温度；温度 ≥70 °C 变橙、≥76 °C 变红。
- 自动降温生效（频率上限已被压到低于设定上限）时，图标外圈显示 **绿框**。
- 左键点击图标：弹出面板，查看温度 / 核心频率 / 功耗 / 风扇 / 占用率 / 显存 / 当前锁频上限 / 当前动作。
- 面板或右键菜单可 **开启/关闭自动降温**（关闭时立即 `--reset-gpu-clocks` 恢复）。
- 可编辑降温规则：降温温度、恢复温度、紧急温度、检测间隔、频率上/下限、升/降频步进、锁频最低值、功耗上限。
- **开机自动启动**：通过计划任务（最高权限、登录时触发）启动，重启后不会弹 UAC。
- 所有配置保存在 `%APPDATA%\GpuGuard\config.json`，重启后自动加载。

## 构建 / 运行
```powershell
.\build.ps1        # 输出 dist\GpuGuard.exe
.\dist\GpuGuard.exe
```
运行需要管理员权限（`nvidia-smi --lock-gpu-clocks` 要求），exe 已带管理员清单，会自动提示 UAC。
需要已安装 .NET 10 桌面运行时。

## 控制方式（锁频 / 限功耗）
面板「控制方式」有三档：
- **自动**（默认）：先尝试 `--lock-gpu-clocks`；显卡/驱动拒绝时自动改用 `--power-limit`，面板会提示「本卡不支持锁频，已自动切换为限功耗降温」。
- **锁频**：只用 `--lock-gpu-clocks`，不支持时显示错误。
- **限功耗**：只用 `--power-limit`。

GeForce 消费卡（RTX 3090 / 30、40 系）在 Windows WDDM 驱动下通常不允许 nvidia-smi 锁频，
而且 nvidia-smi 会把失败当 warning 打印、退出码仍为 0。程序现在按输出文本判断失败，
不会再"假装锁频成功"。3090 的功耗限制范围约 100–350 W，限功耗降温效果很好。
工作站卡（如 RTX PRO 4500，功耗范围只有 150–200 W）则继续走锁频。

参数自动钳位：频率上限不超过显卡 `clocks.max.sm`；锁频最低值不低于显卡支持的最低频率
（Ampere 为 210 MHz）；功耗上限 / 下限为 0 时使用显卡的默认 / 最低功耗限制。

## 降温逻辑
每个检测周期（锁频模式调频率，限功耗模式调功耗，步进各自独立设置）：
- 温度 ≥ 紧急温度 → 上限下调 3×步进
- 温度 > 降温温度 → 下调 1×步进
- 温度 ≤ 恢复温度 且 上限未到顶 → 上调 1×步进
- 上限永远在 [下限, 上限] 之间；锁频范围为 `锁频最低值 ~ 当前上限`

退出程序（托盘菜单「退出」）时自动恢复默认频率与功耗限制。

## 排查
- `%APPDATA%\GpuGuard\guard.log`：显卡能力探测结果、切换控制方式的原因、nvidia-smi 的原始报错。
- `%APPDATA%\GpuGuard\error.log`：程序崩溃堆栈。
- 面板红字为当前周期错误，橙字为非致命提示（如已回退到限功耗）。
